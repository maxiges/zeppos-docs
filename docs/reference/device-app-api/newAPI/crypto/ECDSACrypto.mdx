# Elliptic Curve Digital Signature Algorithm (ECDSA)

The Elliptic Curve Digital Signature Algorithm (ECDSA) is a cryptographically secure asymmetric algorithm used to ensure data integrity, authenticity, and non-repudiation in Zepp OS applications.

### How ECDSA Works in Zepp OS

Unlike symmetric cryptography (such as AES) which uses the same key for both encryption and decryption, ECDSA relies on a mathematically linked **asymmetric key pair**:

1. **Private Key:** Kept securely on the device (or protected via the hardware PUF module). It is used to generate a unique digital signature for a specific chunk of data via a hashing digest.
2. **Public Key:** Can be shared freely. Anyone with access to the public key and the original data can mathematically verify that the signature was generated by the corresponding private key, ensuring the data has not been modified or forged.

> **Note on Naming Conventions:** In this API framework, `encrypt` acts as the cryptographic operation to **Sign** data using a private key, while `decrypt` acts as the operation to **Verify** the signature using a public key.

## createCrypto

Initializes a new ECDSA digital signature instance. By default, the highly popular `ecp_dp.SECP256K1` elliptic curve is utilized.

### Curve Profiles & Constants

| Constant ID        | Description                                                                                 | Supported Key Lengths | API_LEVEL |
| :----------------- | :------------------------------------------------------------------------------------------ | :-------------------: | :-------: |
| `alg.ECDSA`        | Elliptic Curve Digital Signature Algorithm identifier                                       |  Dependent on Curve   |   `3.0`   |
| `ecp_dp.SECP192K1` | Koblitz elliptic curve over a 192-bit prime field.                                          |  192 bits (24 bytes)  |   `3.0`   |
| `ecp_dp.SECP224K1` | Koblitz elliptic curve over a 224-bit prime field.                                          |  224 bits (28 bytes)  |   `3.0`   |
| `ecp_dp.SECP256K1` | Koblitz elliptic curve over a 256-bit prime field (Default, standard for Bitcoin/Ethereum). |  256 bits (32 bytes)  |   `3.0`   |

### Type Definition

```ts
function createCrypto(algorithmId: typeof alg.ECDSA, option?: ECDSAOptions): ECDSACrypto | undefined
```

### Parameter Contexts

#### ECDSAData

Represents the structural payload formats acceptable for raw inputs, hashes, or signatures.

- **Type:** `number[]` | `ArrayBuffer` | `Uint8Array`
- **Description:** Binary container housing data targeted for signing, key loading, or validation.

#### ECDSAOptions

Configuration rules fed into the initial construction factory.

| Property      | Type                                                                                | Required |      Default       | Technical Description & Security Scope                                                                                                                         |
| :------------ | :---------------------------------------------------------------------------------- | :------: | :----------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ecp_dp_mode` | `typeof ecp_dp.SECP192K1` \| `typeof ecp_dp.SECP224K1` \| `typeof ecp_dp.SECP256K1` |    No    | `ecp_dp.SECP256K1` | Explicitly binds the mathematical elliptic curve parameters to govern key generation and scaling bounds.                                                       |
| `key_encrypt` | `boolean` \| `number`                                                               |    No    |        `-`         | Setting this toggles secure hardware wrapping. When active, generated private keys are enveloped by the physical PUF module, making key extraction impossible. |
| `private_key` | `ECDSAData`                                                                         |    No    |        `-`         | Imports an existing, previously generated asymmetric private key buffer instead of spawning a new one.                                                         |
| `pub_key`     | `ECDSAData`                                                                         |    No    |        `-`         | Imports an existing asymmetric public key buffer to be used during high-performance authentication steps.                                                      |

## ECDSACrypto

An instantiated engine containing state parameters, curve algorithms, and execution contexts required to run key management, signing, and signature validations.

### Methods Reference

#### createChiper()

Generates a new, randomized asymmetric public/private key pair bound to the chosen elliptic curve scheme.

```ts
createChiper(): ECDSAKeyResult | undefined
```

- **Returns:** An `ECDSAKeyResult` structural mapping or `undefined` if key generation failed due to low device entropy or parameter bounds.

##### ECDSAKeyResult Schema

| Property             | Type          | Description                                                      |
| :------------------- | :------------ | :--------------------------------------------------------------- |
| `private_key_length` | `number`      | Length of the generated private key string in bytes.             |
| `private_key`        | `ArrayBuffer` | Raw entropy buffer containing the private key parameter.         |
| `pub_key_length`     | `number`      | Length of the generated public key structure in bytes.           |
| `pub_key`            | `ArrayBuffer` | Raw entropy buffer containing the public key coordinate vectors. |

---

#### encrypt()

Generates a unique cryptographic digital signature using the local private key state over a specified block of data.

```ts
encrypt(data: createCrypto.ECDSAData, option: Options): ECDSACipherResult | undefined
```

##### Options Schema

| Property      | Type                                     | Required | Default | Description                                                                                                     |
| :------------ | :--------------------------------------- | :------: | :-----: | :-------------------------------------------------------------------------------------------------------------- |
| `digest_type` | `typeof alg.MD5` \| `typeof alg.HMACMD5` |   Yes    |    -    | Sets the internal hashing algorithm used to compress raw files or streams before executing signature mechanics. |

##### ECDSACipherResult Schema

| Property | Type          | Description                                               |
| :------- | :------------ | :-------------------------------------------------------- |
| `data`   | `ArrayBuffer` | The resulting distinct binary digital signature sequence. |
| `length` | `number`      | Size of the digital signature sequence payload in bytes.  |

---

#### decrypt()

Validates the authenticity of the data by checking the provided signature payload using the loaded public key structure.

```ts
decrypt(data: createCrypto.ECDSAData, option: Options): ECDSACipherResult | undefined
```

##### Options Schema

| Property   | Type                     | Required | Default | Description                                                                                                  |
| :--------- | :----------------------- | :------: | :-----: | :----------------------------------------------------------------------------------------------------------- |
| `sig_data` | `createCrypto.ECDSAData` |   Yes    |    -    | The target binary digital signature payload that requires mathematical verification against the source data. |

##### ECDSACipherResult Schema

| Property | Type          | Description                                                                                         |
| :------- | :------------ | :-------------------------------------------------------------------------------------------------- |
| `data`   | `ArrayBuffer` | Verification execution outcome buffer. Returns truthy metadata if verification passes successfully. |
| `length` | `number`      | Data length of the resulting verification payload bounds.                                           |

Generate an ECDSA key pair using the default SECP256K1 curve, sign data with MD5 digest, then verify the signature.

```js
import { alg, createCrypto, ecp_dp } from '@zos/crypto'

const source = new Uint8Array([1, 2, 3])
const ecdsa = createCrypto(alg.ECDSA, { ecp_dp_mode: ecp_dp.SECP256K1 })
if (!ecdsa) throw new Error('Failed to create ECDSA instance')

const keys = ecdsa.createChiper()
if (!keys) throw new Error('Failed to create key pair')

const signature = ecdsa.encrypt(source, { digest_type: alg.MD5 })
if (signature) {
  const verified = ecdsa.decrypt(source, { sig_data: signature.data })
  if (verified) {
    console.log(`Signature verified, length: ${verified.length}`)
  }
}
```

Compare ECDSA operations across available elliptic curves: SECP192K1, SECP224K1, and SECP256K1.

```js
import { alg, createCrypto, ecp_dp } from '@zos/crypto'

const curves = [ecp_dp.SECP192K1, ecp_dp.SECP224K1, ecp_dp.SECP256K1]
const source = new Uint8Array([4, 5, 6])

for (let i = 0; i < curves.length; i++) {
  const ecdsa = createCrypto(alg.ECDSA, { ecp_dp_mode: curves[i] })
  if (!ecdsa) continue

  const keys = ecdsa.createChiper()
  if (!keys) continue

  const signature = ecdsa.encrypt(source, { digest_type: alg.MD5 })
  if (signature) {
    const verified = ecdsa.decrypt(source, { sig_data: signature.data })
    console.log(`Curve ${i}: key pair created, signature ${verified ? 'verified ✓' : 'failed ✗'}`)
  }
}
```

Create an ECDSA instance with pre-existing private and public keys stored as byte arrays.

```js
import { alg, createCrypto, ecp_dp } from '@zos/crypto'

// Assume we previously generated and stored these keys
const storedPrivateKey = new Uint8Array([
  /* ... 32 bytes of private key data ... */
])
const storedPublicKey = new Uint8Array([
  /* ... 64 bytes of public key data ... */
])

const ecdsa = createCrypto(alg.ECDSA, {
  ecp_dp_mode: ecp_dp.SECP256K1,
  private_key: storedPrivateKey,
  pub_key: storedPublicKey
})
if (!ecdsa) throw new Error('Failed to create ECDSA instance with existing keys')

const source = new Uint8Array([10, 20, 30])
const signature = ecdsa.encrypt(source, { digest_type: alg.MD5 })
if (signature) {
  const verified = ecdsa.decrypt(source, { sig_data: signature.data })
  console.log(`Signature with existing keys verified: ${Boolean(verified)}`)
}
```

  <TabItem value="hardware-key" label="Hardware-Encrypted Key Storage">

Use `key_encrypt` to protect the ECDSA private key with the device's hardware encryption, making it harder to extract.

```js
import { alg, createCrypto, ecp_dp } from '@zos/crypto'

const ecdsa = createCrypto(alg.ECDSA, {
  ecp_dp_mode: ecp_dp.SECP256K1,
  key_encrypt: 1 // Encrypt key with hardware PUF module
})
if (!ecdsa) throw new Error('Failed to create ECDSA instance')

const keys = ecdsa.createChiper()
if (keys) {
  console.log(`Private key (HW encrypted): ${keys.private_key_length} bytes`)
  console.log(`Public key: ${keys.pub_key_length} bytes`)
}
```
